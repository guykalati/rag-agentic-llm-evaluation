A coding agent with a restricted tool surface

The model can list files, read bounded excerpts, replace one exact match and request fixed tests. A gateway checks operations. The evaluation bridge runs isolated CPU jobs. Independent target and regression checks confirm the saved repair.

A retriever that can be compared fairly

I froze the source snapshots and 12 checked references before comparing BM25, dense cosine search and hybrid reciprocal rank fusion. Every strategy uses the same top-three context budget and local answer model.

What the averages miss

Concrete failures, preserved unchanged

Faithful to the wrong API

BM25 retrieves Popen.communicate behavior for a subprocess.run timeout question. The answer is wrong for the task, even though faithfulness scores 1.0. The missing reference evidence is visible in precision and recall.

A correct option gets rejected

The mkdir answers use the right options. The judge gives faithfulness 0 because it objects to "should use" wording. Other verdicts misread valid chunk citations. I recorded the errors without replacing the original scores.

An experiment loop that can reject a proposal

Separate autoresearch-inspired work

The latest candidate did not beat the incumbent

I added history retrieval, bounded proposals, candidate checks and independently reloaded evaluation to an autoresearch-style loop. A completed eight-head TinyStories candidate scored 0.91690 validation bits per byte versus the incumbent's 0.91219. Lower is better, so the incumbent stayed.

This was a verified development experiment. It was not a completed paired comparison proving history retrieval improves model search. Read the result ↗
